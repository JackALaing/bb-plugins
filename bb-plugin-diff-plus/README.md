# Diff Plus

A BB plugin. It adds what the Diff Tree plugin offered and BB's own Diff tab lacks, without replacing BB's diffs or file list:

- **Folder tree.** A folder button in the Diff tab's toolbar shows the changed files as a tree beside the list, with counts and +/- per folder. A click on a folder's icon opens or closes it; a click on its name filters BB's list to `folder/**` through BB's own filter box; a click on a file filters to it and opens its card. Files and folders carry VS Code's vscode-icons glyphs and, at the right, VS Code's git letters (a dot on folders). The tree's right edge drags to change its width; in a tab narrower than 600px the tree goes above the list instead, as Diff Tree's did.

![The folder tree beside the file list in BB's Diff tab, one folder picked](https://raw.githubusercontent.com/nfour/bb-plugins/master/docs/screenshots/diff-plus-tree.png)

Quoting selected lines needs no plugin: BB's diff has its own "Add to chat" (the "+" beside a line, or a click on one line number and a Shift-click on another).

## Why

The Diff Tree plugin re-rendered its whole file tree on every keystroke in the composer, because the component that drew the tree also read the composer's draft. On a 390-file diff that was ~86ms per key and 26 long frames in 25 keys. BB's own Diff tab on the same diff costs nothing while typing (29ms per key, no long frames), so this plugin builds on it.

## How

- The tree is an app overlay that finds each Diff tab by its markup and portals a toggle into its toolbar and a column into the box around its list (`src/Tree.tsx`, `src/diff-tab.ts`). Its files come from the Git plugin's `files` read, called by `server.ts`, for the scope the tab shows, fetched only while the tree is on and again after a git change. The folder logic is pure and tested (`src/folders.ts`).
- The icons are a subset of [vscode-icons](https://github.com/vscode-icons/vscode-icons) (CC BY-SA 4.0, see `THIRD_PARTY_NOTICES.md`), generated by `pnpm --filter bb-plugin-diff-plus icons` from the vscode-icons extension installed in VS Code: `src/icons.css` has one class per icon with its SVG inlined, `src/icon-map.ts` the file names, extensions and folder names that point to them. `src/file-icons.ts` looks a path up VS Code's way (file name, longest dotted extension, language) and is tested. To add an icon, add its id to the lists at the top of `scripts/icons.mjs` and run the script again.
- Styles are plain prefixed classes in `src/styles.css`, not Tailwind utilities (see the workspace AGENTS.md).

BB has no slot beside the Diff tab, so a BB update can move the markup the tree relies on; the tree then quietly does not show.

## Develop

```sh
pnpm --filter bb-plugin-diff-plus test    # node --test, no build
pnpm --filter bb-plugin-diff-plus check   # tsc
bb plugin install ./bb-plugin-diff-plus --yes
bb plugin dev ./bb-plugin-diff-plus
```
